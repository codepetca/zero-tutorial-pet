# Animated pet

Before starting, complete the [account/privacy and Zero setup](https://zero.codepet.ca/help/setup). Create your own repository from this template. On Zero’s Start Page, choose Project → Clone, enter YOUR repository URL and choose Clone here.

The scaffold contains only setup and an empty Main; the first run opens a blank window or canvas. You write the pet, animation and input. Follow [the animated pet lesson](https://zero.codepet.ca/tutorials/13) when the updated tutorials are available, including its separate asset download and attribution. If the lesson or assets are not available yet, try again when they are published. Keep completed checkpoint programs outside this starter.

Run App after each change. Commit & push meaningful checkpoints; review the account, repository and visibility before publishing. If your course uses Pika, submit your repository link there separately.
