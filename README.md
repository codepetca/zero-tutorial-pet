# Animated pet

Before starting, complete the [account/privacy and Zero setup](https://zero.codepet.ca/help/setup). Create your own repository from this template. On Zero’s Start Page, choose Project → Clone, enter YOUR repository URL and choose Clone here.

The scaffold contains only setup and an empty Main; the first run opens a blank window or canvas. You write the pet, animation and input. Follow [the animated pet lesson](https://zero.codepet.ca/tutorials/13) when the updated tutorials are available, including its separate asset download and attribution. Ask your teacher if the lesson or assets are not available yet. Keep completed checkpoint programs outside this starter.

Run App after each change. Commit & push meaningful checkpoints; review the account, repository and visibility before publishing. Submit your own repository link separately in Pika.
